# MattSports

My versión of Adidas website

## 📋 Descripción

MattSports es una réplica del sitio web de Adidas, desarrollada como proyecto personal. Este proyecto demuestra habilidades en desarrollo frontend con tecnologías web modernas.

## 🛠️ Tecnologías Utilizadas

- **HTML** (37.2%) - Estructura de la página
- **CSS** (35.4%) - Estilos y diseño responsivo
- **JavaScript** (27.4%) - Interactividad y funcionalidad

## 📁 Estructura del Proyecto

El proyecto está compuesto principalmente por:
- Archivos HTML para la estructura de las páginas
- Hojas de estilos CSS para el diseño visual
- Scripts JavaScript para funcionalidades interactivas

## 🚀 Características

- Diseño responsivo
- Interfaz inspirada en Adidas
- Componentes interactivos

## 📝 Cómo Usar

1. Clona este repositorio
   ```bash
   git clone https://github.com/devmattiel20/MattSports.git
   ```

2. Abre el archivo `index.html` en tu navegador
